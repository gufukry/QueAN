常见问题

QueAN 支持哪些系统？

目前在 Windows 10/11 x64 上提供便携版（解压即用、不写注册表）。其他平台尚未提供正式安装包。

它是免费的吗？

免费。QueAN 是基于 KAMUCL v1.1.15（MIT）二次开发的第三方非官方版本，保留原始版权与许可声明，与 Mojang 无隶属关系。

可以使用正版账户和离线账户吗？

都可以：支持 Microsoft 正版登录、本地离线身份，以及外置登录（内置 LittleSkin 预设，也可自定义认证服务器）。

应该从哪里下载？

请使用本站底部的下载区域。启动器更新会优先使用本站自建更新源，读取失败时自动回落到 GitHub。

启动器怎么更新？

启动后会自动检查；发现新版本可一键下载。下载会做 SHA256 校验，替换前保留原文件，失败不影响现有安装。
